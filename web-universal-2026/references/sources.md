# Fuentes y revisión tecnológica

Revisión documental inicial: 12 de octubre de 2026. Este paquete contiene instrucciones propias; no es una certificación ni un ranking de «las mejores skills». Volver a consultar documentación oficial al construir un proyecto; la fecha no garantiza actualización automática.

- Skills y detección Codex: https://learn.chatgpt.com/docs/build-skills
- Accesibilidad WCAG 2.2: https://www.w3.org/TR/WCAG22/
- CSS container queries: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Containment/Container_queries
- View Transition API: https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API
- Seguridad verificable OWASP ASVS: https://owasp.org/projects/asvs
- PostgreSQL RLS: https://www.postgresql.org/docs/current/ddl-rowsecurity.html

Consultar cuando aplique (no constituyen un stack obligatorio):
- Next.js: https://nextjs.org/docs/app
- React: https://react.dev/learn
- Astro: https://docs.astro.build/
- Vue: https://vuejs.org/guide/introduction.html
- Vite: https://vite.dev/guide/
- Django: https://docs.djangoproject.com/
- FastAPI: https://fastapi.tiangolo.com/
- MySQL: https://dev.mysql.com/doc/
- SQLite: https://www.sqlite.org/docs.html
- Stripe webhooks: https://docs.stripe.com/webhooks

Para cada decisión dependiente de versión, registrar enlace, fecha de consulta, runtime, versión elegida y resultado del check relevante en documentación del proyecto. Consultar notas de release, compatibilidad y soporte de navegador; no usar blogs de tendencias como única evidencia técnica.
